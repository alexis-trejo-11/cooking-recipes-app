Hi! I'm a passionate full-stack developer who loves building modern, user-friendly web and mobile applications. RecipeBook is a personal project created to showcase my skills in Angular 20, modern UI/UX design, and RESTful API integration.

This application demonstrates my expertise in creating responsive, interactive interfaces using Angular's latest features including signals, control flow syntax, and standalone components. The backend API is built with modern best practices, featuring comprehensive recipe management, user authentication, and social features.

When I'm not coding, I enjoy exploring new technologies, contributing to open source, and of course, trying out new recipes in the kitchen!
